# nilportugues.com

Web personal de Nil Portugués Calderó. Es una web estática sin dependencias ni paso de build: `index.html` (inglés, versión por defecto) y `es/index.html` (castellano). `en/` solo redirige a la raíz para no romper enlaces antiguos.

Para verla en local, abre `index.html` en el navegador o ejecuta `python3 -m http.server`
