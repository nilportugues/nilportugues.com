Software development life cycle

How I ship software

A structured, measurable process from idea to production and back again. This is what I do at each phase.

Planning

  • OKRs and roadmaps aligned with the business.
  • Technical, team and cost feasibility.
  • Initiative plans drafted from PRDs.

Requirements

  • Functional and non-functional requirements.
  • Discovery and delivery epics, and user story maps.
  • Clear acceptance criteria.

Design

  • Architecture with DDD and hexagonal.
  • Data models, APIs and search indexes.
  • Technology chosen for cost and team fit.

Implementation

  • SOLID, coding standards and code review.
  • Legacy refactors without stopping the business.
  • AI agent-assisted development.

Testing

  • Unit, integration and component tests.
  • BDD with Behat and Cucumber; Jest on the front end.
  • E2E coverage scaled with AI.

Deployment

  • CI/CD pipelines and automated builds.
  • Docker, AWS and Google Cloud.
  • Staging and production environments.

Maintenance

  • Monitoring with Prometheus and InfluxDB.
  • Strict SLAs on critical systems.
  • Docs kept in sync with the code.
